# Teh’Lajah Brooks Portfolio

Static HTML/CSS/JavaScript portfolio built for GitHub Pages. No build step is required.

## Publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload the **contents** of this folder to the repository root.
3. Commit and push to `main`.
4. In GitHub, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select `main` and `/ (root)`, then save.

The homepage is `index.html`.

## Structure

- `index.html` — Home
- `portfolio.html` — Filterable portfolio plus separate Global & Cultural collections
- `experience.html` — Experience
- `about.html` — About
- `contact.html` — Contact
- `projects/` — Individual project and collection pages
- `assets/css/styles.css` — Site design system
- `assets/js/main.js` — Mobile navigation and project filtering
- `assets/images/` — Existing portfolio imagery exported from the approved portfolio source

## Editing

All text is directly in the HTML files, so you can edit copy without a framework or build tool.
