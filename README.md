# Teh’Lajah Brooks Portfolio — GitHub Pages

Static HTML site. CSS and navigation JavaScript are embedded in every page to avoid GitHub Pages asset-path issues.

## Upload
Upload the CONTENTS of this folder to the root of the GitHub repository. `index.html` must be visible at the repository root, next to `portfolio.html`, `experience.html`, `about.html`, `contact.html`, `assets/`, and `projects/`.

GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
